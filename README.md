# English Passport — نسخهٔ نقشه راه ۴۳۲ جلسه‌ای

این بسته نسخهٔ بهبودیافتهٔ English Passport را به‌عنوان صفحهٔ اصلی وب‌سایت منتشر می‌کند. نسخهٔ قبلی ۱۸۰روزه نیز برای رجوع در `archive/index-180-day-before-432-upgrade.html` نگهداری شده است.

## انتشار در GitHub Pages

1. از مخزن فعلی یک نسخهٔ پشتیبان بگیرید.
2. محتویات این ZIP را در ریشهٔ مخزن `hassanmotiei.github.io` بارگذاری کنید و تغییرات را commit کنید.
3. فایل `index.html` صفحهٔ اصلی جدید است؛ `sw.js` نیز نسخهٔ کش PWA را به‌روز می‌کند.
4. این موارد حفظ شده‌اند و نباید حذف شوند: `backup.json`، `manifest.webmanifest`، پوشه‌های `assets/` و `icons/`، تست‌ها و فایل‌های مستندات.
5. پس از انتشار، سایت را باز کنید و یک بار صفحه را تازه‌سازی کنید. اگر برنامهٔ نصب‌شده هنوز نسخهٔ قدیمی را نشان می‌دهد، آن را ببندید و دوباره باز کنید؛ سرویس‌ورکر جدید باید کش قبلی `ep-*` را پاک کند.

## قابلیت‌های نسخهٔ ۴۳۲ جلسه‌ای

- نقشهٔ راه جامع از Day 001 تا Day 432.
- ویرایش محتوای روز انتخاب‌شده، شامل عنوان، هدف، تمرین‌ها و خروجی مورد انتظار؛ قابلیت ویرایش برای همهٔ روزها طراحی شده است.
- بهبود چیدمان نقشهٔ راه و ابزارهای روزانه مانند فیلتر روزها، حالت تمرکز، کپی خلاصه و چاپ/ذخیره PDF.
- جعبهٔ لایتنر و ابزارهای مرور واژگان، همراه با سایر بخش‌های موجود در HTML.
- ذخیره‌سازی محلی در مرورگر؛ برای انتقال اطلاعات به دستگاه دیگر باید از قابلیت پشتیبان‌گیری داخل برنامه استفاده شود.

## داده‌ها و سازگاری

`backup.json` موجود بدون تغییر نگه داشته شده است. داده‌های ذخیره‌شده در `localStorage` مرورگر به‌طور خودکار با HTML یا ZIP منتقل نمی‌شوند؛ پیش از پاک‌کردن داده‌های مرورگر یا تغییر دامنه، از داخل برنامه خروجی پشتیبان بگیرید.

فایل‌های `assets/` و `icons/` نیز حفظ شده‌اند تا داده‌ها و منابع قبلی مخزن از دست نروند، هرچند HTML جدید عمدتاً مستقل و درون‌خطی است.

## نسخه‌بندی کش

برای به‌روزرسانی نسخهٔ کش، پس از تغییر `index.html` یا فایل‌های precache شده اجرا کنید:

```bash
python bump_sw_version.py
```

سپس `index.html` و `sw.js` را با هم منتشر کنید.

## آزمون‌ها

آزمون‌های فعلی در `tests/test_progress_dashboard.py` برای بررسی یکپارچگی نسخهٔ ۴۳۲ جلسه‌ای تنظیم شده‌اند. برای اجرای آن‌ها:

```bash
python -m pytest -q
```
