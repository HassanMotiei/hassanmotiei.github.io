# English Passport — نسخهٔ نقشه راه ۴۳۲ جلسه‌ای

این بسته نسخهٔ بهبودیافتهٔ English Passport را به‌عنوان صفحهٔ اصلی وب‌سایت منتشر می‌کند. نسخهٔ پیشین صفحهٔ اصلی در `archive/index-180-day-before-432-upgrade.html` نگهداری شده است.

## انتشار در GitHub Pages

1. پیش از انتشار، در صورت داشتن پیشرفت ذخیره‌شده در مرورگر، از ابزار پشتیبان‌گیری داخل برنامه خروجی بگیر؛ `localStorage` با جایگزینی فایل‌ها منتقل نمی‌شود.
2. فایل‌های داخل این بسته را در ریشهٔ مخزن `HassanMotiei/hassanmotiei.github.io` قرار بده؛ فایل‌ها را داخل پوشهٔ تودرتوی دیگری آپلود نکن.
3. `index.html` صفحهٔ اصلی جدید است و `sw.js` نسخهٔ کش PWA را به‌روز می‌کند.
4. `backup.json`، `manifest.webmanifest`، پوشه‌های `assets/` و `icons/` و سایر فایل‌های موجود را حذف نکن.
5. پس از انتشار، سایت را تازه‌سازی کن. اگر برنامهٔ نصب‌شده هنوز نسخهٔ قدیمی را نشان می‌دهد، آن را کامل ببند و دوباره باز کن.

## قابلیت‌های نسخهٔ ۴۳۲ جلسه‌ای

- نقشهٔ راه جامع از Day 001 تا Day 432.
- ویرایش محتوای روز انتخاب‌شده؛ ویرایشگر برای همهٔ ۴۳۲ روز طراحی شده است.
- جست‌وجو و فیلتر روزها، حالت تمرکز و کپی خلاصهٔ روز.
- زمان‌سنج مطالعه با بازه‌های ۱۰، ۲۵ و ۴۰ دقیقه، همراه با شروع، مکث و بازنشانی.
- تمرین مکالمهٔ فوری با موضوع انگلیسی، ترجمهٔ فارسی و جملهٔ پیشنهادی برای شروع؛ امکان انتخاب موضوع دیگر و کپی آن.
- ابزارهای قبلی برنامه، از جمله مرور لایتنر، پیگیری پیشرفت و پشتیبان‌گیری، حفظ شده‌اند.
- در بخش «نقشه راه جامع انگلیسی» دکمهٔ ذخیره/چاپ به PDF وجود ندارد.

## داده‌ها و سازگاری

`backup.json` و فایل‌های موجود در `assets/` و `icons/` در این بسته حفظ شده‌اند. داده‌های ذخیره‌شده در `localStorage` مرورگر به‌طور خودکار با HTML یا ZIP منتقل نمی‌شوند؛ قبل از پاک‌کردن داده‌های مرورگر یا تغییر دامنه، از داخل برنامه خروجی پشتیبان بگیر.

## نسخه‌بندی کش

پس از تغییر `index.html` یا فایل‌های precache شده، این دستور را اجرا کن:

```bash
python bump_sw_version.py
```

سپس `index.html` و `sw.js` را با هم منتشر کن. در بستهٔ فعلی، نسخهٔ ثبت‌شده در `sw.js` با خروجی `bump_sw_version.py` مطابقت دارد.

## آزمون‌ها

آزمون‌های خودکار در `tests/test_progress_dashboard.py` بررسی‌های پایهٔ ساختار نسخهٔ ۴۳۲ جلسه‌ای، ابزارهای تازه، ابزار لایتنر، دارایی‌های لازم و نسخهٔ Service Worker را انجام می‌دهند. برای اجرا:

```bash
python -m pytest -q
```

آزمون خودکار موفق به معنی تست کامل روی مرورگر و گوشی واقعی نیست؛ پس از انتشار، بازکردن برنامه و امتحان‌کردن ابزارهای جدید روی دستگاه خودت نیز لازم است.
